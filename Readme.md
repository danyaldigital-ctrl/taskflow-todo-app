# TaskFlow - To-Do List Application

TaskFlow is a simple web-based To-Do List application developed for Software Engineering Assignment 01.

## Purpose

The purpose of TaskFlow is to help users manage their daily tasks through a simple and easy-to-use interface.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Display remaining task count
- Save tasks using browser Local Storage
- Responsive design for different screen sizes

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Actions
- GitHub Pages

## How to Run Locally

1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Open `index.html` using Live Server.
4. The application will open in your browser.

## DevOps Workflow

The project follows a basic DevOps workflow:

1. Develop the application
2. Test the application locally
3. Store the source code on GitHub
4. Use meaningful Git commits
5. Run automated checks using GitHub Actions
6. Deploy the application using GitHub Pages
